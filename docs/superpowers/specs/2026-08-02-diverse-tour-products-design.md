# Diverse Tour Products Design

## 목적
현재 `eda_insights.py`에서 제안하는 롤모델 맞춤형 관광 상품 목록과 설명이 하드코딩된 3개의 배열에 의존하고 있어, 타겟 도시나 추천된 롤모델 도시에 관계없이 비슷한 상품이 반복적으로 출력되는 문제를 해결합니다. 생성형 AI API 연동 대신 빠른 렌더링과 독립성을 위해 **풍부한 아이디어 풀(Pool)과 문장 템플릿의 랜덤 조합** 방식을 도입하여 다양성을 극대화합니다.

## 구조 설계

### 1. 풍부한 아이디어 풀(Pool) 구축
- 인프라 카테고리(`OTA 관광 상품`, `공공 추천 여행지`, `지역 축제`, `다국어 가이드`, `세계음식점`)별로 10~15개 이상의 구체적이고 트렌디한 관광 상품 아이디어(제목, 설명)를 정의합니다.
- 예: "다국어 가이드" 카테고리의 경우 기존 3개에서 "글로벌 앰버서더 투어", "스마트 다국어 도슨트", "K-컬처 다국어 체험", "외국인 특화 미식 투어", "다국어 메타버스 가이드" 등 다수 추가.

### 2. 문장 템플릿 세트 구성
- 현재 고정된 단일 문장인 "A의 압도적인 B 인프라를 벤치마킹하여 제안합니다..." 대신 여러 개의 템플릿을 배열로 구성합니다.
- 예: 
  - "성공 사례인 {r_city}의 {best_infra} 인프라를 참고하여 기획한 맞춤형 전략입니다."
  - "{target_city_ml}의 관광 잠재력을 일깨우기 위해, {r_city}가 입증한 {best_infra} 성공 모델을 제안합니다."
  - "롤모델 {r_city}의 {best_infra} 강점을 {target_city_ml}만의 색깔로 재해석하여 도출한 핵심 상품입니다."

### 3. 동적 조합(Randomization) 로직 구현
- `import random`을 추가합니다.
- 롤모델 도시(최대 3개) 각각의 `best_infra`를 추출할 때, 중복된 상품이 나오지 않도록 전체 카테고리별로 `random.sample()`을 사용해 필요한 개수만큼 아이디어를 무작위 추출합니다.
- 문장 템플릿 역시 `random.choice()`를 사용하여 롤모델 도시마다 다른 맥락의 설명이 생성되도록 합니다.

## 검증 방안
- Streamlit 대시보드를 실행하여 서로 다른 타겟 도시를 선택했을 때 3개의 제안 상품이 각각 고유한 제목, 설명, 결론 문구를 가지는지 시각적으로 확인합니다.
- 페이지를 새로고침(또는 타겟 도시 재선택)할 때마다 랜덤 샘플링에 의해 매번 다른 관광 상품 조합이 나오는지 확인합니다.
