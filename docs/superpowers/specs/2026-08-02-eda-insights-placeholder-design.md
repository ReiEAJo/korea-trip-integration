# 롤모델 추천 카드 UI 개선(플레이스홀더) 디자인 명세 (Spec)

## 개요
- **목적**: `eda_insights.py` 내의 롤모델 매칭 카드(최대 3개) 출력 시, 매칭된 롤모델 도시가 1~2개뿐일 때 발생하는 레이아웃 빈 공간을 메우기 위해 3단 그리드를 유지하는 빈 카드를 채워 넣습니다.
- **방식**: 3개의 Streamlit 컬럼에 카드를 차례대로 렌더링하고, 남는 컬럼에는 '추가 탐색 중'이라는 안내 메시지가 담긴 플레이스홀더를 삽입하여 심미적 안정감을 확보합니다.

## 변경 내용
- **대상 파일**: `korea-trip-data/src/views/eda_insights.py`
- **구현 로직**: 
  1. `st.columns(3)` 생성 후 순회 (`for i, col in enumerate(cols):`)
  2. `if i < len(recommended_cities):` 조건을 통해 실제 롤모델 카드를 렌더링
  3. **[추가]** `else:` 분기를 추가하여 실제 롤모델 카드가 들어갈 자리 대신 동일한 형태의 더미 카드를 렌더링
  
## 플레이스홀더 카드 디자인
